# Préparer une argumentation de valeur

## Intention pédagogique

Montrer un support de décision utilisable par les managers. 10 minutes de démonstration du canvas, 0 minute de pratique. L'activité de remplissage vient en MP03.

## OUTILLER — usage et gabarit

Le canvas MET-VALEUR-WORKFLOW complète la comparaison existante des architectures par la mesure de valeur. Une page suffit ; la carte et la grille de risques restent annexées. Réutilisable pour un processus interne, un budget de pilote ou une offre de service bornée.

- Besoin / bénéficiaire / résultat acceptable : …
- Situation de référence : faits … ; inconnues …
- Hypothèse de valeur / mécanisme / mesure : …
- Travail complet / qualité / délai / coût d'exploitation : …
- Limite et contrôle hérité du module 3 / preuve : …
- Essai comparable / responsable proposé / date de revue : …
- Poursuivre si … ; arrêter si … ; prochain pas demandé : …

## Exemple rempli à commenter

Besoin : brouillon RH-042 pour le RH habilité. Référence : temps actuel inconnu, aucune économie établie. Hypothèse : moins de préparation, sans augmentation équivalente des reprises. Mesures : temps humain complet par dossier, pièces correctement citées et incertitude visible ; délai jusqu'à revue séparé. Limite : aucune écriture ou réponse automatique. Essai proposé : deux lots de cinq dossiers fictifs comparables, même grille d'acceptation, autre personne lors du second lot. Responsable proposé : manager d'usage avec relecteur RH. Poursuite proposée : baisse du travail complet avec qualité préservée sur les deux lots ; arrêt si accès hors périmètre ou résultat présenté comme certain sans preuve. Les seuils d'un pilote réel restent une décision du responsable.

## Conseils et principe de correction

Écrire « hypothèse » en face d'un gain inconnu ; une case à mesurer est préférable à un chiffre inventé. Compter le coût initial à part du coût par dossier. Un rôle proposé n'est pas une personne engagée. Un volume pédagogique de dix dossiers ne garantit pas la représentativité statistique. Une validation absente ne devient pas un accord sous la pression du retour sur investissement.

## Déroulé et consolidation

2 min pour l'usage du canvas ; 5 min pour l'exemple rempli ; 2 min pour les pièges ; 1 min pour désigner les supports à reprendre en MP03. Message : « Demander un essai dont on saura interpréter le résultat. »
