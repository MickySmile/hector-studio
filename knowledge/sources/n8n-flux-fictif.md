# n8n — capacités documentées pour un flux fictif

Trois pages officielles consultées le **12 octobre 2026** :

| Repère | Capacité documentée | Page |
| --- | --- | --- |
| N1 | Manual Trigger lance un workflow manuellement, sans déclencheur automatique. | [Manual Trigger](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.manualworkflowtrigger.md) |
| N2 | Edit Fields (Set) ajoute ou remplace des champs ; modes Manual Mapping et JSON Output. | [Edit Fields](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.set) |
| N3 | If oriente le flux selon une comparaison, notamment entre nombres. | [If](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.if.md) |

Les pages ne fournissent pas de date documentaire distincte ni de version
d’instance de session. La réserve de If sur le comportement historique avec Merge
ne prouve rien sur une installation actuelle. Le candidat n’utilise pas Merge.

Confiance forte dans ces capacités documentées, **aucune preuve d’exécution**.
Un branchement n’est ni une habilitation ni une validation humaine. Aucun compte,
accès client, licence, workflow importable ou connexion à un SIRH n’est fourni.
Relire avant usage, au plus tard le 12 novembre 2026 (échéance éditoriale).
